# Codex for Open Source 申请准备

## 当前状态

`v0.1.0` 是项目的首个本地发布候选版本。公开仓库、真实外部使用和
发布后的持续维护记录尚未发生，因此当前不应提交申请。

## 申请前必须核验

- 仓库保持公开并且最近仍有真实维护活动。
- 申请人确实承担主要维护者或核心维护者职责。
- 星标、分叉、下载、Issue、PR 和用户反馈均来自真实外部活动。
- 能以公开证据说明项目的实际使用量、广泛采用度或生态重要性。
- 仓库价值说明和 API 用途说明不超过表单的 500 字符限制。

## API 用途草案

API 额度将用于维护本项目：分析用户提交的自动化配置和日报样例，
辅助分类 Issue、审查 PR、生成兼容性测试，以及检查发布前的文档和
结构变化。额度不会用于刷取 GitHub 指标、制造虚假用户活动或处理
未经授权的敏感数据。

## 提交边界

姓名、ChatGPT 账户邮箱和 OpenAI 组织 ID 仅在用户明确确认后输入
官方表单。最终提交前再次展示全部字段并获得确认。
